# 音效资源

**当前状态：本目录有 15 个 WAV 文件（14 个战斗音效 + 1 个 Boss 环境氛围）。**

**如实说明**：这些是 `tools/generate_audio.py` 用 Python 标准库
（`wave` / `struct` / `math` / `random`）**离线合成**的素材，
**不是专业录音，也没有采样自真实素材库**。它们的定位是"比运行时
合成的占位音好、能撑起打击感判断"，而不是"最终商用音效"。
音色上限受合成方式限制：能听出轻重、能分清命中与挥空、能分清
砍石头与砍血肉，但不会有真实武器的泛音细节。

## 生成方式

```bash
# 生成全部 15 个文件并打印校验表（约 1 秒）
python -I tools/generate_audio.py

# 只做校验，不重新生成
python -I tools/generate_audio.py --verify
```

脚本用固定随机种子，**同一份代码每次跑出的文件逐字节一致**（可复现）。
不依赖 numpy 或任何第三方库。

## 加载方式

`AudioManager._resolve_stream()` 会**优先加载**
`res://assets/audio/<音效键>.wav` 或 `.ogg`，找不到才退回运行时合成的
占位音。所以文件缺失时游戏仍然有声音，不会静音。

Boss 的环境氛围音不在 `AudioManager.SFX_DEFS` 里，由
`scripts/enemy/boss_greatsword.gd` 的 `_setup_ambient_audio()` 自建
`AudioStreamPlayer` 播放（走 `Ambient` 总线，代码里设置循环）。

## 各文件的设计要点

| 文件 | 主要成分 |
|------|----------|
| `swing_light` | 白噪声过带通（中心 1.8k→5.6k→1.1k 扫频）+ 3.4k→1.5k 正弦滑音 |
| `swing_medium` | 同上但峰值降到 3 kHz、衰减拉长 |
| `swing_heavy` | 粉噪声带通 300→1050→220 Hz + 190→70 Hz 三振荡器 + 7 Hz"阵风"调幅 |
| `swing_iai` | 4 个非谐分音（3050/5150/6900/8800 Hz）+ 3.5 kHz 高通瞬态 |
| `hit_light` | 1 ms 全频瞬态 + 1500→820 Hz 主体 + 高通噪声 |
| `hit_medium` | 280→150 Hz 双振荡器 + 3.5 kHz 低通噪声爆 + 瞬态 |
| `hit_heavy` | 135→72 Hz 三振荡器 + 58 Hz 次低频 + 1.2 kHz 低通噪声，末端软削波 |
| `hit_execution` | 52 Hz 次低频 + 110→46 Hz 下扫 + 0.30 s 内 16 段随机脆裂瞬态 |
| `hit_stone` | 1.8 kHz 高通颗粒噪声（320 Hz 随机门）+ 4 次脆裂瞬态 + 2.4k/3.9k 金属分音 |
| `dodge` | 粉噪声带通拱形扫频 500→2600→400 Hz + 对称拱形包络 |
| `died` | 190→48 Hz 三振荡器 + 46 Hz 次低频，**真正的 ADSR**（含 sustain 段） |
| `boss_swing` | 粉噪声带通 120→420 Hz + 150→52 Hz 主体 + 5 Hz"阵风" |
| `boss_hit` | 48 Hz 次低频 + 105→50 Hz 主体 + 700 Hz 低通噪声，重失真 |
| `poise_break` | 金属非谐分音 1 : 1.61 : 2.49 : 3.62 : 5.26 + 两段崩裂瞬态 + 11 Hz 音高抖动 |
| `boss_ambient` | 55/82.5/110/164 Hz 正弦（**吸附到 1/时长 的整数倍**）+ 粉噪声床 + 0.6 Hz 起伏 |

音色塑造手法：ADSR / 指数衰减包络、多振荡器失谐、白噪声与粉噪声、
单极点低通与高通、状态变量滤波器（支持逐样本扫频）、
音高滑落包络、`tanh` 软削波、峰值归一化。
`boss_ambient` 另外用"尾接首交叉淡化 + 频率吸附"保证 6 秒无缝循环
（实测首尾样本差 = 0，接缝处无阶跃）。

## 关于 Godot 的导入设置

WAV 的导入参数写在 `*.wav.import` 里。本项目把
`compress/mode` 从引擎默认的 `2`（VRAM 压缩）改成了 `0`（无压缩 PCM）。
原因：VRAM 压缩对 44.1 kHz 单声道会按 32 分之一的采样率重采样（实测
`hit_heavy` 只剩 1378 Hz 有效采样率），高频全被砍掉。这些文件总共只有
834 KB，没必要为省这点内存牺牲音质；而且一旦重新导入，导入器会立刻
找回原始采样率。

**注意**：重新生成 WAV 后需要重跑一次导入（见下），但 `.import` 文件
不会丢，`compress/mode=0` 会一直保留。

## 音频总线

`default_bus_layout.tres`（由 `tools/generate_audio_buses.gd` 生成）定义了：
`Master ← SFX ← Ambient`。

- **Master**：一级轻压缩（-10 dB / 3:1 / 12 ms 起音），把连击的多次冲击"黏"在一起
- **SFX**：小房间混响（湿声 0.13）+ 打击专用压缩（-16 dB / 3.5:1 / 3 ms 起音）
- **Ambient**：大空间混响（湿声 0.30），供 Boss 环境氛围音使用

`AudioManager` 的 3D 与 2D 播放器池全部挂到 `SFX` 总线；
Boss 环境氛围播放器挂到 `Ambient`。总线名不存在时会退回 `Master`，
不会因为布局缺失而静音。

## 已知不足（不要当成"音频已完成"）

1. **是程序合成的素材，不是专业录音**。没有真实乐器的泛音，仔细听能听出"电子感"。
2. **没有空间化差异**：所有音效都是单声道干声，位置感完全依赖
   `AudioStreamPlayer3D`，没有按距离变化的滤波（远处命中不会变闷）。
3. **没有随机变体**：同一把刀砍同一个目标，每次都是同一个波形
   （只有 `pitch_scale` 的 ±8% 随机）。连续攻击会有轻微"复读"感。
4. **Boss 环境氛围只有一层**：没有随阶段变化的旋律/节奏，
   二阶段没有音频上的强化。
5. 未做响度归一化（LUFS），只做了峰值归一化；各文件的主观响度
   靠 `AudioManager.SFX_DEFS` 里的 `vol` 字段区分。
