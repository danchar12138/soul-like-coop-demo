# 任务清单

每项任务**指定唯一负责人**。并行开发时按此表认领，避免多人同时改同一模块。

**负责人缩写**
- `主干`：项目技术负责人（当前由 AI 承担）
- `美术`：Blender 资源制作
- `联机`：网络同步模块

**状态图例**：✅ 已完成 / 🔶 部分完成 / ⏳ 待开始 / ❌ 阻塞
